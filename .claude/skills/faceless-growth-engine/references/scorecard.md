# Grille d'auto-critique d'un script

Joue l'éditeur sceptique. Pour chaque critère : note 0-5 + une phrase de preuve citant le passage du script. Pas de preuve = 0.

## Portes éliminatoires (échec = réécriture obligatoire)
- [ ] **Exactitude** : aucune affirmation fausse ou invérifiable ; chiffres sourcés ou retirés
- [ ] **Droits & licences** : pas de contenu protégé, médias utilisables commercialement
- [ ] **Honnêteté** : titre et hook tiennent leur promesse, pas de clickbait trompeur
- [ ] **Dans la niche** : sert le positionnement verrouillé
- [ ] **Non interchangeable** : apporte un angle, une info ou une structure qu'on ne retrouve pas partout

## Critères notés (0-5)
| Critère | Ce qu'un 5 ressemble |
|---|---|
| Hook (0-3 s) | Crée une curiosité ou un enjeu immédiat, compris sans le son, pas d'intro ni de "salut les amis" |
| Promesse & payoff | La promesse du hook est livrée, et le gain pour le spectateur est clair |
| Rythme & rétention | Une nouvelle info ou un changement visuel toutes les 2-4 s, pas de creux, aucune phrase inutile |
| Clarté | Une idée par phrase, vocabulaire de la cible, compréhensible à la première écoute |
| Valeur unique | Une info, une mise en perspective ou un exemple concret mémorable |
| Visuels | Mots-clés visuels précis par scène, cohérents avec le texte (pas de stock générique hors sujet) |
| Fin & boucle | Fin nette, CTA naturel et unique, idéalement bouclage vers le début |
| Titre / description | Titre clair + mot-clé, description utile, 3-5 hashtags pertinents |
| Cohérence de marque | Ton, voix, format conformes à `channel-state.md` |

## Verdict
- Score = total / 45. **Seuil : >= 80 % et aucun critère < 3.**
- Sinon : liste les 2-3 corrections les plus rentables, réécris, re-note. **Maximum 2 boucles.**
- Garde-fou anti-indulgence : si tout est >= 4 au premier passage, cherche activement les 3 faiblesses les plus probables et re-note.

## Format de rapport (à montrer à l'utilisateur)
**Score final : X/45** | Portes : OK / [échec]
Points forts (1-2) · Faiblesses restantes (1-2) · Ce que la critique a changé (2-3 lignes)
